Moderation
in package
  • Application
implements Module

FinalYes
Moderation.php : 53

Everything a moderator needs that Discord's own UI doesn't give a bot-run server: numbered cases, a persistent warning history with escalation, notes, scheduled tempbans and timeouts, filtered message purges, channel lockdown with restore, and a "report to *this server's* mods" message command.

Native actions (kick / ban / timeout / slowmode / permission overwrites) are thin wrappers that additionally write a CaseBook case and post it to the guild's modlog (or log) channel. Everything is one /mod command with sub-commands, guild-only, gated on Permissions::MODERATOR plus a role hierarchy check.
